# Project Case Study Checklist

An objective technical checklist for preparing a project case study.

- [ ] **Narrative Completeness**: Does the README follow the Problem -> Context -> Requirement -> Approach -> Design -> Analysis -> Iteration -> Validation -> Result -> Limitations flow?
- [ ] **Source Files**: Are all relevant source files (CAD, code, notebooks) included or correctly linked?
- [ ] **Code Publication Safety**: Have secrets, API keys, and proprietary algorithms been removed?
- [ ] **Asset Attribution**: Are all external assets and references properly attributed?
- [ ] **Evidence Verification**: Has all evidence passed the `evidence-ingestion-protocol.md`?
- [ ] **Confidentiality**: Does this project comply with NDA/research embargo requirements?
- [ ] **Reproducibility**: Are results reproducible based on the provided data/models?
- [ ] **Results Verification**: Are the results objectively verified and accurate?
- [ ] **Limitations**: Are limitations explicitly stated?
- [ ] **Publication Review**: Has the project passed the final `REVIEW_GATE.md` publication check?
